The One-Line Cat Joke That Lands: a single original joke about cats, one line under 200 characters, with a setup and a turn that lands — no pun, no explanation after the punchline. `main.ts` (Node 22, standard library only) writes the joke to `entry.txt` and validates it against the brief's gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/cat-joke-out node main.ts
cat /tmp/cat-joke-out/entry.txt
```
